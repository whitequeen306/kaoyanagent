# 分值策略（推导分值）

更新：2026-11-18。用户已接受「推导分值」，但产品界面必须明确标注，不能伪装成官方逐题分值。

## 依据

- 官方试卷只公布题型总分：选择题、填空题、解答题各占多少分；不公布每题分值。
- 2019 年文都公开了数学二逐题分值、难度与区分度，可作为第三方校验：
  - 选择 8×4、填空 6×4、解答 5×10 + 4×11 = 94，总分 150。
  - 来源：https://kaoyan.wendu.com/m/2019/1113/147612.shtml

## 推导规则

| 年份 | 选择 | 填空 | 解答分配 | 合计 |
|---|---|---|---|---|
| 2005–2006 | 8×4 | 6×4 | 5×10 + 4×11 | 150 |
| 2007 | 10×4 | 6×4 | 5×10 + 3×12 | 150 |
| 2008–2020 | 8×4 | 6×4 | 5×10 + 4×11 | 150 |
| 2021–2026 | 10×5 | 6×5 | 1×10 + 5×12 | 150 |

- 选择题、填空题按官方每题分值直接分配。
- 解答题按题型总分分配；同一题型内前几题较低、后几题较高。
- 2019 年使用文都公开的逐题分值覆盖推导值，并标注 `score_source = third_party_wendu_2019`。
- 其余年份标注 `score_source = derived_section_structure`、`score_status = derived`。

## 产品要求

- 试卷与题目界面必须显示「推导分值」提示，不能声称是官方评分。
- 判卷总分与得分率可以正常计算，但对外文案要说明分值来源。
- 若后续拿到权威逐题分值，只需替换 `score_x2` 与 `score_source`，不改判卷逻辑。
